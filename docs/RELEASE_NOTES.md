# Wendy's Dash v1.0.0

The first public release of the Windows GUI patcher.

- Hold Xbox **X** or keyboard **Shift** to run at **2x walking speed**.
- Automatically locate Steam installations, or choose the game folder manually.
- Apply and undo the change with verified backups.
- See patch status and operation details in the app.

Download **`WendyQuestDashPatcher.exe`** from the assets below, close the game, and open it. Confirm the game folder and select **Apply patch**. The optional ZIP includes the same executable, usage notes, and a checksum.

Requires Windows and .NET Framework 4.8 or newer. The application is unsigned and distributed under the MIT license. No game files are included. This is an unofficial community patch.
